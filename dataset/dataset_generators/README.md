# Dataset Generators

This directory contains the Python scripts used to generate synthetic vulnerability datasets for the **VulnSneak** AI platform.

Each generator produces realistic vulnerable and secure code pairs following a unified JSONL schema. These datasets are used to train and evaluate VulnSneak's AI models for both vulnerability detection and automated code repair.

---

## Available Generators

| Generator | Vulnerability | Description |
|-----------|---------------|-------------|
| `generate_sqli.py` | SQL Injection | Generates vulnerable SQL queries and secure parameterized implementations. |
| `generate_xss.py` | Cross-Site Scripting (XSS) | Produces reflected and stored XSS samples together with secure fixes. |
| `generate_csrf.py` | Cross-Site Request Forgery (CSRF) | Generates state-changing requests with and without CSRF protection. |
| `generate_path_traversal.py` | Path Traversal | Creates insecure file access examples and secure path validation implementations. |
| `generate_deserialization.py` | Insecure Deserialization | Generates unsafe deserialization samples and secure alternatives. |
| `generate_command_injection.py` | OS Command Injection | Produces command execution vulnerabilities and secure command handling examples. |
| `generate_xml_injection.py` | XML Injection | Generates XML, XPath, and XXE-related vulnerabilities together with secure implementations. |
| `generate_cryptography.py` | Insecure Cryptography | Produces weak cryptographic implementations and their secure alternatives. |

---

## Shared Utilities

All generators rely on the reusable modules located in the **utils/** directory.

These shared components provide:

- Configuration management
- Text processing
- Output parsing
- Duplicate detection
- Logging
- Sample validation
- Common helper functions

Using shared utilities keeps every generator consistent, reduces duplicated code, and simplifies long-term maintenance.

## Output Format

Each generated sample follows the unified dataset schema.

```json
{
  "vuln_code": "...",
  "safe_code": "...",
  "state": "SQL Injection",
  "safe_code_label": "Safe"
}
```

The unified format allows datasets generated by different scripts to be merged seamlessly for vulnerability detection and secure code repair tasks.

## Usage

1. Install the required dependencies:

```bash
pip install -r requirements.txt
```

2. Configure your environment:

```bash
cp .env.example .env
```

3. Run any generator:

```bash
python generate_sqli.py
```

or

```bash
python generate_xss.py
```

Each generator creates its own JSONL dataset for a single vulnerability family.

---

## Notes

- Every generator is independent.
- All generators share the common utilities in the `utils/` package.
- Generated datasets follow the schema defined in `schema.json`.
- The generation pipeline includes validation and duplicate filtering before exporting samples.
- The generated datasets are intended for AI training, evaluation, and cybersecurity research.

## Disclaimer

The generated vulnerable code samples are provided **solely for educational purposes, cybersecurity research, and AI model training**.
